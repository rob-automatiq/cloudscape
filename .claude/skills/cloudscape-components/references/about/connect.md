# Connect

> Source: https://cloudscape.design/about/connect/ (fetched 2026-09-24)

If you want to go fast, go alone. If you want to go far, go together. Connect with the Cloudscape team through one of the channels below.

## Participate in the community

### Ask a question

Have a question? Open a discussion with the Cloudscape team on GitHub.

 [Ask a question on GitHub](https://github.com/cloudscape-design/components/discussions)
### Feature request

Not finding what you need? Ask the Cloudscape team to add it to the system.

 [Request a feature on GitHub](https://github.com/cloudscape-design/components/issues/new?template=2_feature_request.yaml)
### Figma feature request

Request a feature for our Figma library.

 [Request a Figma library feature](https://github.com/cloudscape-design/components/issues/new?template=5_figma_feature_request.yaml)
## Report an issue

### Bug report

Something broken? Let us know.

 [Report a bug on GitHub](https://github.com/cloudscape-design/components/issues/new?template=1_bug_report.yaml)
### Report a Figma bug

Report a bug in our Figma library.

 [Report a Figma library bug](https://github.com/cloudscape-design/components/issues/new?template=4_figma_bug_report.yaml)
### Documentation

Report an issue or suggest an improvement to our documentation.

 [Report an issue on GitHub](https://github.com/cloudscape-design/components/issues/new?template=3_documentation.yaml)
### Security vulnerability

If you discover a potential security issue in this project, we ask that you notify AWS/Amazon Security via our vulnerability reporting page. Please do **not** create a public GitHub issue.

 [Report a security vulnerability](https://aws.amazon.com/security/vulnerability-reporting/)---
